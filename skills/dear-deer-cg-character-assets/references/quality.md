# 角色资产图检查与返工

“专家级”指结构完整、选择有依据、生成后逐项检查与可追踪返工。质量结论采用通过／需修／未验证；不要写虚构的百分制或“细节完美”。

## 四级检查

1. **缩略图**：在用户实际观看尺度下，头／体／服装轮廓、色块、关键配件可辨；五方向不能只在极小纹理上不同。
2. **完整视图**：拓扑正确、全身完整、比例稳定、站姿／服装／光影相容，配件有合理固定方式。
3. **原尺寸局部**：脸、头发、耳颈、眼鼻唇、手与物件、闭合与衣料层次、缝线补片、鞋底与接触、重要文字。
4. **跨图对照**：母版、近景、侧背、表情和细节共享同一身份与版本；以角色自身左右核验，不能从不可见部分推断通过。

记录可观察问题和对应图片／部位。必要时用确定性工具做局部裁图或对照页供检查，不能用脚本重画角色代替生成。

## 必查项与判断

| 项目 | 通过证据 | 返工触发 |
|---|---|---|
| 剧情与期望 | 外观支持已给身份、世界条件与用户选择 | 变成不同职业、擅改年龄／性别／物种、混入未来剧情道具 |
| 拓扑与义体 | 肢体数量及附肢符合锁定卡，义肢替换关系清楚 | 多肢、少肢、误删NH/X合理结构、替换关系混乱 |
| 面部身份 | 脸型与眉眼鼻口颌、年龄感一致；独特结构可读 | 同服不同脸、塑料面孔、近景与全身骨相不符 |
| 发型与左右 | 分缝／额发／后颈／眉断口位置明确 | 镜像换边、头发结构漂移、把缺毛变成伤口 |
| 服装构造 | 各层领口、肩袖、闭合、下摆、裤鞋连贯 | 层次互穿、口袋无口、补片丢失、正背衣长变化 |
| 配件功能 | 位置、固定、大小和动作可用 | 悬浮、凭空换手、饰物无固定点、收纳不能使用 |
| 材质与细节 | 布／皮／金属／橡胶区别可读，细节按层级分布 | 所有材质同样反光、蜡皮、过度锐化、磨损杂乱 |
| 手和关键交互 | 可见结构与持握关系正确，遮挡有依据 | 融合手指、手穿物、物件与手无接触 |
| 构图与裁切 | 本轮所需部位完整，重要结构不被遮挡 | 肩／鞋／尾翼裁切、身份特写广角变脸 |
| 多视图空间 | 尺度、服装和附肢位置一致，参考方向清楚 | 背面换造型、把背面不见的表情当识别证据 |
| 表情与状态 | 表情肌变化保留骨相，服装伤势符合变体 | 表情改年龄／五官比例、未来伤势混入当前 |
| 可交付与可引用 | 实际文件可打开，版本与选定记录一致 | 只有提示词／缩略图、引用旧图、未检查就称母版 |

无法完整数清被遮挡的手指时标未验证，换清楚角度再查，不声称“十指通过”。不得把所有项目“看起来不错”当证据。

## 问题分级与修法

- 阻断：身份、拓扑、重要剧情道具、错误左右或关键衣装结构失真。修好前不扩派生包。
- 重要：多视图比例／材质失衡、细节难辨、关键裁切。修改相关图和消费者，保留无影响部分。
- 可选：无剧情作用的微纹样、背景细微噪点。向用户说明局限，别反复重生成整个人。

按问题表保存：版本／视图／实际问题／需变部位／保留项／修法／实际复核／影响的后续素材。一次修一组相关缺陷，禁止同时加新装饰造成无法比较。

## 交付状态

文字设计完成、候选图已生成、视觉检查通过、用户已选母版、多视图一致性通过和镜头应用通过分别记录。基础包通过不证明真实三维模型、动作视频、绑定骨骼或所有后续镜头稳定。

交付完整卡片和图像清单；展示用户需要的一项决定与具体限制。用户选择不替代视觉检查，视觉通过也不能自动选定审美。
