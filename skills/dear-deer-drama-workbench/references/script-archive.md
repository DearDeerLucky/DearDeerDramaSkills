# 历史恢复与剧本归档

用于指定作品的旧对话恢复、总稿整理、历史版本及可下载归档；挂在 N14，也可独立执行。它不要求先完成成片，不自动改写剧情或推进发布。用 [归档记录模板](../assets/script-archive-template.md) 在创作目录保存本轮依据和续做入口。

## 作品、底本与恢复范围

- 先绑定用户最后确认的作品分支、需要保留的集数和规划范围。同一长对话可能包含不同题材；对话标题不是作品身份，也不能据此混入其他作品。既有集／场／镜头编号保留，不为归档重新编号全部资产。
- 分清用户指定母本、实际取得的正文、现行分镜、历史提案和审稿意见。文件修改时间、标题里的“最终稿”或旧文里的“已确定”都不能单独证明最新批准；有用户确认原话时关联消息和版本。
- 优先读取已给材料与当前创作目录，再按线索定位历史原件、相关会话、Library或资源指南。只查与本作品有关的文件；保留原目录，不为整理而移动或清理来源。
- 会话读取记录实际返回的回合范围、消息ID、时间与翻页情况。遇到内容引用占位符、缺失附件或截断，记录原始返回及缺失正文；无更多游标不等于完整长对话已经恢复。引用索引和会话摘要不能代替所指的完整正文。
- Library资源清单、历史SHA、可搜索的文件名与已下载原件分开。没有真实文件搜索能力时明确说明；其他类型的页面列表没有命中，不能证明Library不存在文件。不得把历史文件名拼成未验证的下载链接。
- 指定母本正文无法取得时，完成不依赖它的恢复和整理；交付标题明确为“现存资料归档版”等实际状态，说明采用哪一底本及哪些内容不能核对。补充说明列最小必要的消息、导出文件或附件；未核实当前界面时不编造具体导出菜单路径。

## 证据、时间线与版本关系

| 标记 | 用法 |
|---|---|
| 原话证据 | 实际取得的消息或文件原文；注明是用户消息、助手文本、文件原文还是来源自报，并给可定位位置 |
| 摘要转述 | 对已取得材料的整理，关联来源，不用引号冒充逐字原话 |
| 推定 | 由多项材料推导的判断，说明依据和仍不能确定的部分 |
| 缺失／待核 | 未取得或冲突未解的正文、附件、确认、版本关系和资源状态 |

时间线注明时区，并区分消息时间、文件自报时间、文件修改时间和本次取回时间。保留关键原话与消息ID；“可以”“继续”等依赖上下文的短答，缺少前文时不能绑定成具体方案的批准。资料时间先后和文本差异不证明作者因某条审稿意见而改稿。

历史原稿、审稿建议、候选改稿、确认版分别存放。否决表区分用户明确否决、旧稿规则排除、现行稿未采用和缺少结论；没有人类否决原话时不补造理由。文本diff只证明文字变化，不证明直接父子版本或采纳过程。

## 总稿、附录与来源

按用户要求组织交付；简单整理无需生成全套空附件。完整归档通常包含：

- 正式总稿：注明当前底本、适用范围、母本缺口和版本。现行分集与未来季／集规划分开；规划体量不是已写完的集数。
- 讨论过程与决策时间线：关键原话、讨论摘要、可确认决定和仍未决定的事项。
- 独立历史附录：保留取得的历史全文；未采用／否决方案和审稿建议各有状态，不回填进现行剧情。
- 素材与来源索引：来源编号、原始名称／位置、取得范围、包内路径、字节数、SHA-256、是否实取。资源指南中引用但未取回的包单独列出。
- 版本差异与待核清单：影响人物、规则、时序、供货／交易等连续性的差异，已知缺口、最小补档资料及补回后的核对顺序。

从分镜PDF恢复正文时保留集／场／帧编号和来源页码；折行合并、同镜头重复台词去重等转录处理要说明。制作来源说明不混作对白。若依据明确勘误修正，记录旧文、新文、适用位置和勘误来源；原件仍保留旧文字。镜头参数、图像与文件SHA可留在带图原件及提取文本中，不宣称转录已取得原始可录制剧本。

来源副本保持字节不变，派生转录和摘要另存。索引中的本次计算SHA与历史清单自报SHA分开。机器缺少字体、原始剧本或真实媒体时保留限制，不以静态审阅资料证明时长可演、配音完成或成片通过。

## DOCX、PDF、链接与ZIP验收

用户要求相应格式时使用当前可用的 documents／pdf 专用 Skill。可复用已有生成与验证工具，不把一次作品的固定路径、字体目录、凭据或临时脚本写成通用依赖。

- DOCX须由实际文档工具读取并渲染；PDF须可解析并逐页看图，核对中文、页眉页码、表格跨页、截断与空白页。PDF能提取中文不代表字形实际可见；检查实际字体和嵌入结果。
- 按用户范围核对集数、唯一场／帧编号、关键动作与台词的对应，尤其是重复对白与有依据的勘误。没有提供完整正文时不写“与母本逐字一致”。
- 本地链接采用可迁移的相对路径，检查Word书签、DOCX／PDF／导航中的目标与包内文件；提示完整解压后使用。外部入口单独记录当前可访问性、账户权限或未验证状态，不把本地目标存在称作远端下载已通过。
- ZIP打包后校验CRC，并在独立临时目录实际解压、回读文件SHA；核对原件与冻结来源一致。保留来源表、校验清单和验证结论，最终包内不混入中间渲染缓存、环境备份或无关作品。

分别报告文件结构／读取、排版视觉、内容对应、链接、ZIP与原始材料恢复程度；未做的检查如实列出。文件通过不等于作者最终定稿、配音或成片验收。

## 补档后的续做

保留当前归档，先核对补回的母本及用户最新决定，再比对现行分集、原始剧本与历史方案；只对有证据的差异修改。更新来源索引、待核项与受影响节点，另出归档版本，不静默覆盖旧包。作品记录留在创作目录；可复用方法写入Skill，具体剧本和本机路径不进入公开Skill源。
