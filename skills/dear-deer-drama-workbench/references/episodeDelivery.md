# 整集制作与交付验收

用于 N07—N13 的整集任务，以及回答“现在能否从剧本做到成片”。单张资产或单镜试用仍按对应节点执行，不要求补齐整集记录。由 Agent 根据现有材料填写，作品与证据保存在创作目录，不进入技能源。

## 先核对实际能力

区分流程规范、工具可调用、样片已生成、样片视听通过、整集交付通过。它们说明不同范围，沿用工作台的 Skill 状态和制作状态，并在证据中注明实际验证对象。安装 Skill、发现模型、MCP 读取成功或存在输出文件，均不能独立证明媒体质量或整集完成。

| 环节 | 当前工具与输入 | 实际验证对象／证据 | 尚未覆盖 | 本集处理办法 |
|---|---|---|---|---|

例如，五秒后期样片通过，只能覆盖该样片和已检查的项目；任意时长、多角色声线和多镜头混音分别核对。没有整集自动编排工具时，可以用当前可用剪辑工具由 Agent 分阶段组织；只有实际合成并验收后才能说整集跑通。已有能力可继续使用，缺口只阻塞依赖它的产物。

## N07—N09：把镜头变成可剪素材

1. 沿用已确认的集数、时长、画幅和风格。将当前分集逐场映射到镜头，保留剧情动作、信息和对白；根据对白朗读与动作预演校准时间，估计和实测分别记录。
2. 为镜头引用实际选定的角色、服装、场景、道具及声音版本。复用母版；参考 ID 还需对应当前工具可访问的文件。相邻镜头核对站位、视线、光源和道具起止状态。
3. 生成时记录实际任务标识、参数、输出与检查结果；先使用已授权的样片检查动作难度和风格，再在同范围扩批。工具只支持固定时长时，按可用区间剪入，不直接用“镜头数 × 生成时长”代替成片时长。

复用 [cards.md](cards.md) 的分镜与批次卡。进入剪辑后，在需要时补充以下清单，秒数或帧号单位保持一致：

| 镜头 ID／选定版本 | 源文件／实际时长 | 源剪入—剪出 | 成片开始—结束 | 原声处理／对白引用 | 转场重叠 | 检查状态 |
|---|---|---|---|---|---|---|

原始视频、剪辑选用版本和最终成片分别保存。未采用的重试结果不能自动替换已选镜头。

## N10：先确定声音路线

| 路线 | 对白处理 | 后期处理与验收重点 |
|---|---|---|
| 保留原生声音 | 保留视频实际对白 | 先试听，再按实际语音对齐字幕、增补音乐与音效；混音不重复叠加同句对白 |
| 后期配音 | 按最终对白与角色声音卡制作 | 明确替换哪些原声；分离不可用时不能声称已单独保留原环境声，必要时重建 |
| 混合使用 | 逐镜登记保留或替换 | 核对角色声线与声场跨镜连续性、接缝及重复对白，不能默认原生声音跨镜一致 |

调用前核对处理器是否会替换整个音轨。保留原声的任务不能直接送入只支持全轨替换的处理器；先保留源文件并选择匹配工具，缺能力时登记待补，不将字幕方案当作实际完成。

声音卡除声线和读音外，记录实际供应商／模型、音色或参考版本及试听结果（不记密钥）。只有自然语言声线描述不能保证声音可复现。字幕依据最终保留或混合后的实际对白对齐，不能只用剧本文字等分镜头时长；静音也可以是明确的创作选择。

## N11：按实际时间线合成

- 先粗剪验证剧情、对白与节奏，再精剪。核对素材剪入区间有效，时间线无非预期空隙、漏镜、占位或重复；淡化等转场的重叠计算在实际合成中核实。
- 整集时长取实际时间线与导出结果，不能简单累加含重叠的源片时长。帧率转换、变速和裁切不能造成口型、对白或画幅问题；目标规格和可接受偏差沿用制作卡，不凭空指定平台要求。
- 字幕检查错别字、专名、标点、分行、遮挡与可读时间；旁白和画外音标记与内容相符。烧录字幕、可选字幕轨、独立字幕文件分别说明实际交付形式。
- 混音核对对白清楚、跨镜音量衔接、音乐和音效不遮盖对白、切点没有突跳或截断。仅在已有交付规格时按其响度、峰值等指标测量，不套用未经核对的通用数值。

## 失败续做与多设备交接

记录能恢复任务的最少信息：镜头／任务编号、输入版本、工具与参数、任务标识、执行设备或负责人、提交时间、输出位置、状态与失败原因。状态描述实际任务情况，不虚构后台队列或锁功能。

超时或连接中断后，先查原任务与输出，判断仍运行、已完成或失败，再决定是否重试。恢复时重用有效结果；输入变化只重做受影响镜头及其后续合成。不同设备领取独立镜头或任务，交接选定版本和当前状态；MCP 连通不意味着具有任务锁、实时画布同步或自动冲突合并。

## N12—N13：整集交付凭据

| 验收项 | 通过依据 | 实际结果／问题时间点 | 证据或检查方式 |
|---|---|---|---|
| 内容与连续性 | 剧情可理解，无关键漏镜；角色、服装、场景和道具状态连续 | | |
| 动态画面 | 无影响观看的变形、闪烁、穿模或错误运动 | | |
| 声音与字幕 | 对白字音、字幕、同步和混音符合已确认方案 | | |
| 文件与规格 | 实际导出可解码、可播放，时长、尺寸、帧率与声音符合制作卡 | | |
| 整集视听 | 实际从头到尾回看并试听最终导出，修复主要问题后复核受影响段落 | | |
| 交付位置 | 文件、画布节点、素材库或客户端副本分别核对本次要求的目标 | | |

技术检查可用当前工具读取媒体元数据并完整解码，检查异常、截断和音视频轨；这些结果不能代替视听质量。单帧、抽帧、语音识别只能辅助对应检查，不能声称已覆盖全片动态、声音表演或精确口型。当前环境无法实际回看或试听时，保留待视听验收，并把可播放文件交给可检查的一方。

验收绑定具体导出版本、时间和检查方式；修改后复核变更及其衔接，结论不能沿用到未检查的新导出。影响理解、身份识别、对白或交付规格的问题保持待修，其他已知限制明确列出。交付时报告视频及所需字幕／素材索引、已通过的检查和剩余问题；未做的项目写未验证，不按通过比例宣布整集完成。公开发布另按实际授权和回执报告。
