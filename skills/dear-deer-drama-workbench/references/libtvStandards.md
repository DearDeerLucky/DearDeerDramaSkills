# LibTV 流程与制作标准

在导入 LibTV 材料、整理剧本五栏目、检查资产连续性或搭建制作流程时读取。执行提示词见 [promptTemplates.md](promptTemplates.md)，Toonflow 的实际读写与回传见 [toonflowBridge.md](toonflowBridge.md)。保留现有 N00—N15 编号与 CG 角色专用流程。

## 来源和适用范围

2026-10-19 根据经用户授权读取的 LibTV 剧本编辑器，以及用户提供的角色锚点操作记录整理。可见内容包括故事大纲、人物小传、场景设计、道具设计、分集正文，以及登记角色锚点、建立图片节点、回读状态的操作顺序。

这是对可见资料结构和制作方法的适配，不是 LibTV 内部系统提示词、隐藏技能或后端实现的副本。具体作品链接、原文快照、节点 ID 和验证记录保留在创作项目或本仓库忽略的 `.local/`，不进入通用技能源。模板中的数量、风格和时长依用户项目决定。

## 五类剧本资料

| 栏目 | 制作字段 | 通过标准与消费者 |
| --- | --- | --- |
| 故事大纲 | 一句话故事、核心看点、情绪曲线、故事简述、背景规则；长篇按需增加阶段目标、信息释放、钩子、伏笔、创作禁区 | 主角有可见行动，转折有因果，世界规则有代价；支撑 N01、N02 与连续性检查 |
| 人物小传 | 类型、人物设定、戏剧作用、标签、语言风格、说话破绽、记忆点、弧光、急迫时的行动、称呼、别名或口头禅、首次出场及关键集次 | 动机、行为和对白可区分；已知事实与视觉设计候选分开；交给 N03、N04 |
| 场景设计 | 场景名称、别名、内外景、戏剧作用、空间对行动的限制、可复用动作位置、出现集次 | 人物能实际行动，出入口、设施与动线可延续；交给 N05、N07 |
| 道具设计 | 名称、类型、别名、戏剧作用、使用边界、持有与状态、首次出场及关键集次 | 物件功能、来源和限制说得通，开合、损坏和持有者跨镜一致；交给 N06、N07 |
| 分集剧本 | 集标题、目标时长、节拍、核心氛围；场次编号、地点、时间、内外景、人物、动作、台词、必要声音 | 每场推动状态变化，动作可表现，台词能读完；交给 N03、N07、N10 |

按当前阶段补必要字段，不要求用户填全表，也不把原资料缺项补成既成事实。原文存在重复、矛盾或空项时，先保留导入快照，将建议修订另列；只有用户要求改稿才写入修订版。

### 大纲与季结构

- 阶段表按需要记录「从何状态到何状态」、集数范围、信息释放及本阶段与其他阶段的差异。大纲提到外部详稿时登记其实际存在性；一个文件引用不等于已经读取该文件。
- 钩子记录画面或台词、引发的疑问及落点；伏笔记录埋设形态、埋入位置、回收位置和回收方式。修改上游后沿引用核对消费者。
- 创作禁区写可观察的限制：解决问题的知识或资源从何而来、角色不能突然改变什么、结局需要哪些前置证据。专业事实另做可靠来源核验，不能用戏剧文本证明医学或工程事实。
- 样例中的长篇集数、单集时长、人物数量和场次数是作品规格，不是所有漫剧的默认规格。

### 从小传到资产

人物小传解释“为什么行动”，视觉卡解释“如何保持同一个人”。用同一 CHAR ID 关联，不用服装相同代替身份一致。人物三视图、面部近景、装备细节和配色按后续镜头需要选择，不强制所有角色产出同一套拼板。

场景的小传字段补充 [cards.md](cards.md) 的空间布局、固定光源和变体；道具小传补充尺度、机械关系、持握和开合状态。拆单只覆盖本次制作范围，避免为全季未使用资产提前生成图片。

## 锚点与生成记录

1. 读取目标剧本和用户已选图，确认角色、场景、道具范围；已有文件引用按实际工具读取。
2. 登记资产编号、剧本来源、锁定事实、当前候选或母版版本、所需视图和共享画风。可复用的已选图片作为风格或身份参考，不自动把风格参考当新角色的脸。
3. 准备节点和提示词，区分“已建立节点”“参数已填写”“实际生成”“图像检查”“用户选定”。已有当前阶段授权就继续，不因每个节点而重复询问许可；缺少关键风格或范围选择时给可审阅方案。
4. 操作后重新读取实际节点和文件，核对用户或其他设备是否已有产出，再回填记录；未运行节点不能写为生成完成。
5. 只修当前缺陷。保留已选身份、服装与道具版本、通过的视图以及失败原因；重生成不覆盖历史母版。

CG 角色仍由 `dear-deer-cg-character-assets` 负责五方向、脸发与衣装选择和细节检查；本参考不把二维漫剧改成三维，也不把多视图图片叫工程模型。

## 从分集到镜头

先按动作或信息变化拆分，再确定景别与机位。分镜表保存场次、镜头 ID、资产版本、动作、起止状态、对白与声音、预估及实测时长。一个五秒模型能力不意味着一场戏能装进五秒；无法容纳时拆镜或调整表演，不擅自删剧情。

关键帧使用实际可访问的参考图；角色设定拼板不能直接冒充镜头首帧。视频提示词明确主体动作、镜头移动及声音路线；原生有声与后期配音二选一或按明确混音方案衔接，不能叠出重复对白。

## 交付检查

| 检查对象 | 实际检查 |
| --- | --- |
| 剧本 | 五栏目和分集引用完整、人物称呼稳定、钩子伏笔有位置、场次变化与时长可执行 |
| 资产 | 身份、左右、服装、道具形状状态、空间与光源一致；明确候选及母版 |
| 镜头 | 动作达到意图，身份无明显漂移，无严重多肢、穿模、闪烁；实际时长与声音正确 |
| 成片 | 实际回看对白、字幕、音量、音画和镜头连续性；导出文件能播放 |
| 工具衔接 | 使用实际返回路径，区分服务器文件、画布节点、全局素材库和客户端副本 |

只有资料结构和工具调用通过，不能说明画面、口型和表演已经通过。问题回到受影响的 N 阶段处理，保留其余可用素材。
