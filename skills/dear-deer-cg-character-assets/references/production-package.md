# 完整角色图片资产生产规范

用于用户要求制作或续做完整角色资产的任务。它是后续完整角色包的默认标准；单张修图、视觉探索、文字咨询和Skill维护不自动扩成整包，也不因此启动媒体生成。

## 默认交付与参考职责

一个角色的同一服装／剧情状态使用一个CHAR编号和一个当前版本。标准人类角色包共11张独立PNG：

| 文件 | 内容 | 后续引用职责 |
|---|---|---|
| `01_front.png` | 中性正面全身母版 | 比例、体态、逐层衣装、主色块、配件位置；兼作三向正面 |
| `02_identity.png` | 中性身份头肩近景 | 脸型、年龄气质、五官、发型与领口；兼作中性表情 |
| `03_right.png` | 角色自身右侧面全身 | 鼻唇侧轮廓、后方发尾、衣摆、背包厚度与鞋侧 |
| `04_back.png` | 背面全身 | 后方发型、衣装、包体、挂件与鞋跟 |
| `05_happy.png` | 开心 | 眉眼口角变化，保留同一骨相 |
| `06_surprised.png` | 惊讶 | 抬眉、睁眼、小幅张口的可辨变化 |
| `07_angry.png` | 生气／坚定 | 眉头、视线和口部张力 |
| `08_proud.png` | 得意／机灵 | 与开心可区分的克制表演 |
| `09_speechless.png` | 无语 | 与中性、生气可区分的反应 |
| `10_costumeDetails.png` | 衣装材质细节板 | 领肩袖、腰与口袋、手套／手、鞋与落地结构 |
| `11_equipmentDetails.png` | 装备与连接细节板 | 现有包、挂件、收纳与人体的固定和接触关系 |

六种表情包含02中性，不另生成第十二张。05—09是默认情绪槽位，剧本需要的情绪优先，可改名并登记对应关系。无装备时不凭空加包或武器，将11调整为角色已有的关键结构特写或明确不适用。非人拓扑按身体计划补充／替换视角，不把人类三向数量当成其结构已完整覆盖。

配套交付是设计锁定卡、实际提示词、检查记录、便携清单及[IP总览面板与交接包](ip-panel-delivery.md)。面板属于presentation，不计为新的角色原图。

## 从现有设计续做

1. 读取原图、批注、版本与用户已给事实。已有合适的候选或母版直接进入相应阶段，不为补流程重做五方向、重选脸或擅改剧情年龄。职业、身高、关系和故事未提供就保留缺口。
2. 记录用户选择或委托原话、采用版本和不可变项。用户授权“持续做完、需要判断再停”时，沿同范围推进检查与修复；只在身份／拓扑冲突、实质审美分岔或超出既有范围时停下来说明具体问题。
3. 确立01和02的职责并对照核验。脸部调整只改变指定结构，保留年龄身份、发型、衣装和体态；可爱气质不自动改变成年角色的年龄与比例。近景顶部头发、肩部和领口要可读，裁切先修复再扩包。
4. 按01、02生成侧面，再以全身和侧面补背面。没有来源的后方结构标为本轮补全设计，不能声称精确还原。先解决基础身份、拓扑、主要衣装和左右错误，再扩大派生范围。
5. 以02为表情身份依据，保持同一取景、光线、发型与衣装。逐张生成与查看；表情变化应来自眉眼、口角和张力，不能重新设计脸。
6. 用已通过的全身与转面做10、11。细节板可包含多个清楚分开的局部，但只放大既有结构；展示材质差异和连接链路，不新增装饰、工程爆炸图或伪尺寸。被遮挡处仍记未验证。
7. 完成[质量检查](quality.md)及必要定向修复，更新受影响的派生图和记录。再做固定排版、最终导出与打包；不因某张图已返回而直接宣布完整包通过。

每次保存实际工具、完整提示词、真实参考文件、实际参数、输出、版本和检查。未提供随机种子／参考权重的工具不补写虚构参数。旧候选和修复前文件保留历史，交付索引只指向当前采用版本。

## 可复用提示词与附图方法

使用[generation.md](generation.md)的固定层、角色变量层、输出层和排除层。以下任务段要填入本角色的具体结构并附实际参考文件；CHAR编号不能替代附图。

| 输出 | 必要参考 | 本轮任务段要点 |
|---|---|---|
| 身份近景 | 当前全身母版；已有选定脸图优先 | 同一角色，中性正面头肩；仅提高身份可读性，完整头发与肩领口，保留具体年龄、脸型和鼻唇比例 |
| 自身右侧 | 全身＋身份近景 | 严格角色自身右侧，明确鼻子朝画面哪边；统一尺度、站姿与光照，保持发尾、包体厚度和配件自身左右；远侧物件允许自然遮挡 |
| 背面 | 全身＋已核验侧面 | 严格背面，同一衣装、后方发型、包体和接地点；逐件说明自身哪侧及其背视画面位置，不为展示挂件而换边 |
| 表情 | 中性身份近景 | 只改指定情绪的眉眼、口角与肌肉张力；同一骨相、年龄、发型、领口、景别、光线和背景，无新剧情道具 |
| 衣装细节 | 全身＋侧背面 | 分块展示本角色已有的领袖、衣料层次、腰部闭合／收纳、手部和鞋；只保留实际需要且可读的局部 |
| 装备连接 | 具有该物件的全身／转面 | 从人体／包体固定点到扣环／带再到物件的可见连接链路；同一位置、尺度、口袋数量和材质，不悬浮、不复制物件 |

通用保留段可以写为：

```text
为[角色ID／当前版本]制作[指定视图或表情]的CG风格图片参考。
以[身份近景文件]控制面部和发型，以[全身母版文件]控制体态、衣装和配件，以[转面／细节文件]控制[指定结构]。
保留：[完整列出本角色锁定的脸发、年龄体态、逐层衣装、材质色块、配件位置与连接]。
仅改变：[本轮视角／表情／要补清的局部]。
构图：[景别、朝向、完整可见范围、边距、比例、背景和光照]。
所有左右以角色自身为准：[具体标记、物件及在本视角的画面位置]。
不新增：[与当前角色相关的错误结构或道具]。遮挡部分保持合理遮挡，不镜像换边。
```

这只是可填模板。交付prompts必须保存真正发送给工具的完整最终文本、附图关系和修复提示，不能只交未填写的骨架。
