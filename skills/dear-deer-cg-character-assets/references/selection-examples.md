# 选择文案与参考示例图

## 同轮交付

实际创建角色、探索外观或继续选择时，默认把选项文案与对应可见图片放在同一次交付中。文案说明差异、理由和代价；图片帮助用户看清这些结构。保持已有选择，不为了增加示例重新询问或重做已选轮次。

每项显示稳定编号、简短说明、对应图片、图中应看的差异和检查限制。图片与编号一一对应；对照页在同次文字中列清面板顺序。不得把图片搜索词、提示词、未打开的链接或尚未生成的占位当作可见示例。

| 当前选择 | 示例应展示什么 | 必须保持的比较条件 |
|---|---|---|
| 期望询问 | 若提供写实程度、脸型或衣装等视觉选项，配能解释差异的观感参考 | 已有题材、性别、年龄范围与拓扑；身份未定时先补最关键输入，不为问卷生成完整包 |
| R1 五个整体方向 | D01—D05 各一张全身造型示例，能读脸发、轮廓、衣装与主要配件 | 同取景、站姿、光线、背景、CG 材质强度及年龄范围 |
| R2 脸与头发 | 本轮各候选的头肩近景，能读眉眼、鼻口、颧颌与发型 | 已选整体方向、服装领口、年龄与拓扑；近景只变本轮脸发结构 |
| R3 衣装与配件 | 本轮各候选的全身示例；必要细节在检查后补局部近景 | 已选脸、发式、体态与拓扑；本轮只变允许的衣装、鞋与配件 |

通常 R1 为五项，R2／R3 各三项，数量遵循当前设计轮与用户范围。用户委托直接定稿、明确跳过某轮或已选具体脸服饰时，不强制生成未需要的对照。

## 参考从哪里来

1. 先检查用户提供的图片、已生成候选和实际可读的设计记录。合适的旧图可继续作为对应示例，注明来源和能说明的部位，无需为了配图重复生成。
2. 外部参考必须来自已读取或实际查看的来源，标注来源链接和“仅参考脸型／剪裁”等用途；未看图不能声称它匹配。没有合适参考时，用当前已绑定图片工具做本轮候选。外部参考不自动成为角色身份或可用于成片的正式素材。
3. 按 [generation.md](generation.md) 选择通路：Toonflow 内先读桥接并发现实时节点与供应商，其他环境读当前 imagegen Skill。各个不同设计使用各自完整提示和输出；需要对照页时，可将检查过的原图做确定性排版，原图保留。对照页不替代可读近景，也不证明多个面板是同一身份。

最小交付是一项一个足以比较的示例，无需把所有候选生成三视图、表情包或完整资产套装。实际创建角色且没有只做文字的限制时，示例属于本轮外观探索；已有同范围授权继续执行。维护 Skill、只读盘点和明确只做文字的任务只更新定义或文字，不能借配图规则扩大执行范围。用户有生成数量、成本上限或指定服务时沿用它们；不足以覆盖本轮时先缩小到其已授权范围并说明余项，不能自动增加付费批次。

## 已选脸尚无图像

R3 沿用文字选定的脸时，先用完整脸发描述生成一张本轮的身份近景参考并检查。标为“文字已选脸的临时图像参考，待用户视觉确认”，不要求用户重新选一次相同文字方案，也不把这张图升级为正式母版。

将实际近景文件作为衣装示例的脸发参考；衣装只变本轮允许项。已有可读、已选脸图时直接使用。工具不能附参考或输出脸漂移时明确限制并修复，不能只写“保持 F03”就宣称身份绑定成功。若临时参考明显不符合已选文字，先修它，不拿错误脸扩生成整轮示例。

## 检查与记录

打开每张示例，检查是否足以支持当前选择：编号对应，文案结构可见，锁定项保留，候选差异没有被不同姿势或照明掩盖。参考图明显不符时修正图或文案中的未选建议，不擅改已选内容。

选择示例、文字设计已选、候选图检查通过、用户已选图和正式全身母版分别记录。选择了示例编号也不自动证明手、鞋、背面或动作已通过；被遮挡、分辨率不足及图文不一致处写具体限制。

在角色设计记录保存轮次、选项编号、示例用途、来源或实际文件、对应提示与输入版本、检查结果和用户选择。作品图片、提示词和检查结果留在独立创作目录或忽略的本机目录，公开 Skill 只保留通用规范与模板。

工具不可用或生成失败时，保留文案和已获得的真实参考，清楚标明哪些选项缺图及下一步；不宣称视觉示例完成，不用脚本重画占位角色。是否先按文字选择由用户决定，缺图不能被当作默认同意。
