# Dear Deer 3D CG 角色资产

交付有辨识度、能支持后续镜头的角色图片和可续做的设计记录。用具体结构和实际图像检验质量；不以“专家级”“完美”“UE5”几个词代替设计，不承诺一次生成就无缺陷。

可独立调用，或从 Dear Deer 短漫剧创作工作台 N04 接入。保留剧情身份、用户已选外观与资产编号；全身母版、面部细节和转面参考共同服务同一角色。实际生成调用当前可用 imagegen 并读取其 Skill。图片不等于 .glb/.fbx/.obj/.blend 工程模型。

## 入口与当前阶段

- **无提示／描述很少**：按 [references/discovery.md](references/discovery.md) 先问最有影响的一项期望，用易懂的选择帮助用户表达；有回复再筛选五方向。
- **已有提示／剧本**：先提取已给事实、目标和不可变项，询问尚未表达且会影响五方向的期望，不重问已有答案。充分表达期望的提示可以直接出五方向。
- **已有角色图**：先看图和批注，区分用户选定图与候选图；保留已选身份，五方向用于允许变化的维度。纯转绘或精确修图直接进入对应操作，不强制重新选脸。
- **继续选择／生成／修复**：先恢复角色设计与选择记录；只处理当前步骤，读对应参考。不因为换会话而重新探索已锁定项。

## 探索、选择与锁定

按 [references/discovery.md](references/discovery.md) 筛选 **恰好五个**满足当前约束的方向。给出为什么入选、差异与代价；“最优”只针对用户已表达的期望和本次制作约束。选项要能画出来，不能只换配色或气质标签。

实际创建角色时，选择文案默认配对应的**可见参考示例图**，与选项编号一起交付，不让用户只凭术语想象。按 [references/selection-examples.md](references/selection-examples.md) 复用合适的已有参考，或调用当前 imagegen 生成本轮最小示例；整体方向看全身，脸发看近景，衣装比较保留已选脸与头发。用户明确只要文字时遵从该范围；示例不可用时说明缺项，不能把提示词当图片。

按 [references/design-rounds.md](references/design-rounds.md) 进行多轮选择：整体方向 → 面部与头发 → 服装与配件 → 完整设计复核。默认每轮只提出当前的一项选择；用户可以组合局部、退回、修改，或授权跳过某轮。已确认的部分稳定，未确认部分保持候选。用户明确授权自行决定时继续完成，记录所用假设。

使用 [assets/character-design-record.md](assets/character-design-record.md) 保存剧情事实、物种拓扑、五方向、选择理由、脸部结构、发向、服装构造、配件位置、材质、左右、变体和资产版本。未填写字段写具体缺口或“不适用”，不用“等”省略关键结构。

## 生成与检查

按 [references/generation.md](references/generation.md) 选择路径：从文字直接做 CG，或将已选二维母版转 CG。按用户实际范围交付身份近景、全身母版、三方向、表情或服装状态；不要求先生成多余的二维图。

按 [references/quality.md](references/quality.md) 打开并检查生成文件；识别问题后定向修复，同范围授权继续执行。脸、发向、衣服、配件、拓扑、左右和多视图都要核对；看不清的细节标“未验证”，不算通过。生成成功与设计通过分别记录。

保持单一当前全身母版；身份近景是同版本的补充依据。选定前可做候选探索，用户选择或明确委托选择后才升级正式引用。修图不同时重设计无关内容；新图检查通过后更新消费者，原图保留。

## 交付与网页衔接

实际图像直接展示，附简短检查结论和当前需要的一项选择。可复制的完整提示词、设计卡、图像版本和修复记录保存到独立创作目录；不写入无关代码库或 Skill 安装目录。

用户要求网页比较或整理资料时，接入 dear-deer-drama-workbench 的网页模式：显示五方向与各轮资料位、实际图片、选用状态、待补项和决策记录。网页只有文件与用户记录，不能凭按钮声称生成、核验或制作已完成。

Skill 重构／只读盘点／明确的文字试用不自动生成示例或角色图片；实际创建角色的选择示例按上述规则随文案提供，正式资产按用户指定范围生成。第三方工具、模型、批次数量与成本按当前事实核验，不沿用参考平台的固定名单。
