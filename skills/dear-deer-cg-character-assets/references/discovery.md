# 期望询问与五方向筛选

## 恢复已有内容

先读本轮输入及已有设计记录。建立五栏：原稿事实、用户明确要求、已选资产、可调整内容、待确认期望。参考截图不代表采用其角色或模型；无批注图片只能提供可见事实，不能推断用户“喜欢”的审美。既有候选可以比较，但不自动成为母版。

检查任务究竟要新角色、改已有角色、转 CG、转面还是精修。对于精修／介质转换，仅变化用户允许的项，已有完整外观时无需五个新角色。

## 有提示和无提示都能进入

用一次简短回述说明已知目标，再询问一个最影响当前设计的问题，必要时提供三项具体选择和自由补充入口。不要让新手一次填写专业问卷，也不要只问“什么风格”。

无提示示例：“你最想做哪种角色观感？A 接近真人比例、表面细节自然；B 保留真实材质、脸和轮廓更鲜明；C 暂不确定，希望比较不同程度。你也可以描述角色用途。”随后按回答追问下一项必要内容。

有剧情但没有审美目标示例：“角色是地下种菜的研究员，身份已经明确。你更重视普通劳动者的可信感、主角的脸部辨识度，还是成熟 CG 的材质表现？”这是期望询问，不预设其中一个一定更好。

有明确提示示例：“已知你要求成熟脸型、非偶像面孔、简洁工装、无装甲。我会沿用这些条件；五方向只比较具体脸部结构、衣服剪裁与功能配件。”可以直接提出五方向，再让用户选择。

用户“先给我五个看看”“你先自由设计”即允许在注明假设下出五方向，不为形式而再问。用户“全部由你决定并生成”允许根据明确目标推荐并落地，记录主观假设，仍检查实际输出。

优先补的内容按影响排列：剧情用途／世界规则 → 人类或非人形结构 → 用户明确期望和禁区 → 写实与夸张程度／年龄体态 → 实际交付与使用场景。低影响材质细节先列建议，不能以未知鞋带颜色阻塞五方向。

## 物种与拓扑先锁

每角色选一个路径：H 标准人类；NH 近人形；X 完全非人形。X 再写基础拓扑：双足兽形／四足／蛇形／节肢／无定形／构装体。记录头、躯干、肢体数量、附肢、尾、翼、角、皮肤覆盖、义体替换关系和明确禁区。

信息足以从用户材料确定时自行填卡；会改变肢体结构且无法确定时只问这个问题。NH/X 的已确认额外肢体与非人比例不能被通用人类负向提示“修正”掉。人类义肢须明确替换哪条肢体，不自动多长一条手臂。

## 五个方向必须有内容

方向编号固定 D01—D05，名字描述一个可见主结构。每方向含以下八项，每项至少一句具体描述：

1. **脸与头**：脸长宽关系、额头、眉骨、眼窝、眼距与眼睑、颧骨、鼻梁鼻尖、嘴唇与口角、下颌／下巴。选择最能区分该方向的结构详述，其余在完整设计卡补齐。
2. **头发／覆盖物**：分缝、额发落向、耳部露出、后颈、发束轮廓；左右用角色自身坐标。
3. **体态与大轮廓**：头身关系、肩宽、躯干／四肢比例、站姿和重心，不用“帅气”“强大”代替形体。
4. **服装构造**：内外层、领口、肩线、衣长、袖口、闭合、腰线、裤腿、鞋型及活动余量。
5. **色彩与材质位置**：主色落在哪件衣物，强调色具体位置；布、金属、皮革、橡胶如何区分，磨损由使用形成。
6. **配件与器具**：名称、剧情功能、固定位置、持握／开合方式；装饰需有角色依据，不能把配件数量当精细度。
7. **识别点**：远看一个轮廓、近看一个面部结构、中景一个服装或配件结构。疤痕、年龄痕迹、徽记有具体依据或标为建议；不把同一疤痕加到所有候选。
8. **入选理由与代价**：如何贴合剧情和期望；相比其他方案在哪些镜头、变体或细节上更难保持。

五方向至少在三个可变结构轴上明显不同，且至少一个为脸部结构、一个为服装轮廓。已锁脸时改为允许变化的轴，并解释为何不改脸；不能用改变物种、剧情身份或未授权的年龄性别制造差异。用相同视角／光线／背景比较视觉小样，避免靠摆姿势或美化光线伪造胜出。

在内部先考虑更广的合理候选，依据剧情适配、用户期望、识别度、镜头可用性与制作稳定性筛出五个；用户看到入选依据和关键取舍，不需要一大页淘汰草案。先检查硬约束，再比较优缺点。没有用户反馈时只能说“按当前条件最匹配”，不宣称已知用户审美或客观最美。

用短对比表展示五方向的关键差异，完整八项保存在每张方向卡，随时可展开。推荐一个首选和一个备选，理由可追溯；推荐不等于替用户选定。结尾只问：“你想以哪一个为主？也可以指定某方向的脸、另一方向的服装，或告诉我需要重做的部分。”

默认五个是**文字设计方向**。只有用户要求视觉小样时才按实际范围生成五方向图；“给五方向”不自动授权五套完整资产包。
