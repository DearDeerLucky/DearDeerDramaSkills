# Codex 创作工作区与续做

## 定位当前作品

本 Skill 的名称是 Dear Deer 短漫剧创作工作台，调用名为 `dear-deer-drama-workbench`。作品由用户的材料与选择决定；参考截图的故事、角色、模型或平台不成为默认设定。

在首次真正创作时记录项目名称与独立输出目录。用户指定目录就沿用；当前目录是无关软件仓库时，使用另一个可写创作工作区并告知路径。不要把作品写进 `~/.codex/skills`，也不要在无关仓库安装剪辑或生成依赖。

## 本地工作台

按当前任务实际需要创建文件，而不是开始就铺满空目录：

- 制作卡与进度：作品规格、本次范围、N00—N15 的制作状态与能力状态、下一步。
- 故事与分集：原稿、确认版、修订记录；多集按 EP 编号区分。
- 资产卡与素材：CHAR／LOC／PROP 编号、母版、状态变体、用户选择记录。
- 分镜与镜头：EP-SH 编号、资产版本、提示词、起止画面与实际输出。
- 声音与时间线：最终对白、音轨、字幕、粗剪和精剪。
- 交付：可运行预览、可播放视频、必要来源记录与问题单。

节点是可续做的制作单元。默认用本地 Markdown 卡片与进度表承载；不要求依赖任何第三方画布。每张卡有用途、输入、输出、依赖、实际工具／Skill、两类状态、通过标准和下一步。

## 网页工作台

用户要求网页展示时按 [web-workbench.md](web-workbench.md) 复用已保留的本地模板，使用独立网页输出目录。已有作品文件只复制和引用，缺项留等待添加位；浏览器本机记录不是原稿和文件备份。清单导出、素材包、单文件网页与公开发布分别说明。

## 跨会话恢复

先读制作卡与进度，核对用户最新范围、当前已选版本和可用素材，再读取相关环节材料。不重问已有选择，不把旧候选当母版；不从旧价格、工具名单或 Skill 状态推断当前外部能力。

用户说“继续 N05”时，检查 N05 的实际输入并推进场景卡与空间草案；未授权生图时先交文字卡。缺角色母版不阻止准备场景空间；缺专业事实或剧情正文时只让依赖它的正式产物等待。

## 选择工具与外部平台

Codex 的文字、可用 imagegen 和 Remotion 路线见能力登记表，使用前读取对应 Skill。真实 AI 视频和 TTS 按当前实际工具核验；缺失时保存待补节点和可用输入。

只在用户明确选择某平台、导入或要求建立画布时才操作它。读当前页面与已有项目，保留原稿，用真实可见的输入和产出验证结果。Skill 导入、节点创建、素材引用、生成与公开发布是不同动作。

需要迁移时可按目标格式导出文字卡片与素材包；未经核验格式只能称节点清单或粘贴稿，不能声称可批量导入。选择外部工具不能自行改变画风、体量、成本或发布目标。

## 重阶段与输出核验

大量生图、视频渲染或依赖安装前核对当前空间、资源与已有占用；按当前环境的共享资源规则执行，不为本项目擅停其他任务。只是写剧本或卡片时无需启动渲染环境。

预览可运行、画面可见、声音可听、文件可播放、公开发布分别验收。工具调用成功只能证明它返回了结果；产物必须打开检查。交付给新手看得懂的进度、产物路径与下一步，隐藏无助于判断的中间实现细节。
