# 漫剧制作提示词

使用前读取 [libtvStandards.md](libtvStandards.md) 中与当前阶段有关的标准。下列提示词由已观察的 LibTV 资料结构改写，适配当前技能；不是声称提取到的 LibTV 隐藏系统 prompt。花括号是需由实际项目替换的输入，模板本身不启动生成。

每次只选当前任务需要的一段。已确认事实、用户选择、参考版本和当次授权优先；不为填模板而重新询问已有答案，也不把未读文件写成已读。媒体模型参数以当前工具返回的 schema 为准。

## N01 大纲与结构

```text
基于{原稿与版本}和{制作卡}整理故事大纲，保留已确定的题材、体量、主角目标、世界规则与结局方向。
输出：一句话故事、核心看点、情绪曲线、故事简述、背景规则；多集项目按需补阶段表、钩子、伏笔和创作禁区。
每个阶段写清从何状态到何状态、信息释放和与前后阶段的区别。伏笔写明具体埋设形态与回收方式。
只处理{本次范围}；与原稿冲突或需要补写的地方列为候选，不擅自定稿。标出影响制作的具体专业事实待核验项。
检查主角行动是否推动结果，转折是否有前置原因，世界限制是否被遵守。
```

## N02 分集正文

```text
读取{大纲版本}、{人物/场景/道具资料}，完成或修订{目标集}，目标时长和画幅沿用制作卡。
先列节拍与核心氛围，再写集标题和逐场正文：场次编号、地点、时间、内外景、出场人物、可见动作、对白及必要声音。
保持人物语言风格、称呼、道具使用边界和场景动线。每场有目标、阻碍及状态变化；结尾兑现本集行动并留下适合当前故事的追问。
已有原文先保留。只改{明确修订目标}；没有提供的剧情或外观标为建议。不要因为全剧有多集而批量写完整季。
检查对白朗读和动作是否装得进目标时长；估计与实测分开记录，超时给出删减或拆分建议。
```

## N03 资产拆单

```text
只从{已选分集及版本}拆出本次可见资产，复用{现有资产表及母版}。
输出 CHAR、LOC、PROP 编号、名称、来源场次、剧情用途、需用状态/服装/伤势变体、现有母版和待补项。
不把自己推断的外观当原稿事实，不为普通背景杂物强建独立卡。不执行媒体生成。
检查每场人物、地点和推动动作的关键物件都有引用，相同资产的状态变化可追踪。
```

## N04 角色锚点

LibTV 可见的用户任务原句为：“请基于这个剧本节点的人物设定（characters.md）为每个主要角色生成角色图，风格与剧本基调一致。”其中文件名是源项目引用，不能据此假定本机存在该文件。执行时改为实际可读资料：

```text
读取{剧本节点/文件}的人物小传和{已选画风/参考图}，为{本次明确的角色范围}准备角色锚点。
先登记 CHAR ID、剧情身份、不可变外观、服装与随身道具、参考图用途及所需视图。风格参考用于材质和版式，身份参考用于同一角色，二者不要混淆。
沿用已选角色和已有合格图；只有需要探索的部分才给候选。CG 任务接入现有 CG 专用 skill，不强制二维转 CG。
当前任务若只要求准备，交付锚点记录和完整提示词，不生图；已经授权生成则按指定数量与范围执行。
生成后检查同一身份、拓扑和左右、服装层次、装备状态及跨视图一致性，再记录实际文件与选用状态。
```

图像正文可按此组织，引用图片须实际传给模型：

```text
为同一角色制作{所需视图/单张镜头}。身份参考：{实际图片及用途}。
保留{锁定的脸型、体态、发向、服装和标志物}；角色状态为{当前变体}。
表现形式与画风：{已选风格}；构图、背景和照明：{本次要求}。
仅展示{本次需要的视图与细节}，保持各视图为同一人；排除{已识别的具体结构错误}。
```

## N05 场景与 N06 道具

```text
根据{已选剧本和场次}整理{LOC/PROP ID}，保留{已有母版及状态版本}。
场景：写明戏剧作用、空间对行动的限制、门窗与设备相对位置、可复用动作位置、固定光源和所需变体。
道具：写明戏剧作用、使用边界、材质形状、相对尺度、持有或装配关系、开合/工作/损坏状态及出现位置。
只为{本次镜头需求}准备图像视角。精确文字可留后期；实际结构不确定时列待确认项，不能凭空加入万能功能。
交付可引用的卡片和图像提示词；是否生成按当前任务授权执行。
```

## N07 分镜与 N08 首帧

```text
将{已选分集和版本}转为分镜，引用{已选 CHAR/LOC/PROP 版本}，保留原剧情、关键动作和台词。
每镜记录：镜头 ID、来源场次、观众获得的信息、站位视线与轴线、景别机位、动作起止、画面与镜头运动、对白声音、时长估计及资产引用。
一个镜头集中表达一个可辨动作或信息变化。复杂多角色、手部交互或过长对白拆镜，不通过压快语速掩盖超时。
为{目标镜头}写单张首帧提示词：主体和实际参考绑定、起始姿态、空间构图、光线风格，以及具体排除项。角色多视图拼板不能直接当最终首帧。
这里只做{当前授权范围}，图像或视频未生成时保持待制作状态。
```

## N09 原生有声镜头

只用于当前模型实际支持原生声音的分支。将素材路径、时长、分辨率和音频开关作为工具参数，不只写在自然语言里。

```text
Preserve the subject identity, clothing, prop state and scene layout from the supplied first frame.
One continuous shot: {one clear action and starting/ending state}. Camera: {movement and speed}.
{Speaker S1 and selected voice description} speaks {exact approved dialogue} at a natural pace within {feasible timing}.
Only the specified speaker talks. Keep speech and visible mouth movement consistent. Sound: {approved ambience/music or no music}.
No subtitles or on-screen text unless explicitly requested. Preserve {locked visual features}; avoid {specific observed defect}.
```

在现有本地 H3 适配中，可将准确台词写为 `The speaker (S1) says: <d>[Chinese] {准确台词}</d>`。其他供应商不自动支持同一标记语法；先查看实际适配说明。先回看及试听，再判断台词、音色和口型，不以“有音轨”推断表演通过。

## N10 后期声音与 N11 合成

```text
处理{已生成视频与实际路径}，采用{明确的原生音轨保留/后期配音路线}。
准确对白为{最终台词}，角色语气与读音沿用{声音卡}。字幕依据实际音轨对齐，音乐不遮盖对白。
原片已有对白时先核对保留或替换方案，不重叠两份声音；本地配音字幕音乐流程会替换原音轨，不能用于默默保留 H3 原声。
输出到独立镜头目录，记录实际视频、音轨和字幕结果。回看时长、字音、字幕、音量和音画同步；局部未验收项单列。
```

## 续做与定向修复

```text
重新读取{制作卡、剧本版本、已选资产和实际节点/文件}，从{目标 N 阶段/镜头}继续。
区分已经创建的节点、参数、生成文件、图像检查和当前选定版本。其他设备已经产出的文件先复用，不能把旧记录当当前状态。
只修{具体缺陷}，保留{身份/服装/空间/道具/剧情锁定项}，沿消费者记录更新受影响引用。
若剧本文档 revision 冲突，保留草稿，重读并合并后再写；若生成超时先检查原任务，不盲目重投。
```
