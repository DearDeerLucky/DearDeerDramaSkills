# 视频提示词：从导演意图到真实输入

用于 N07—N09 的创作、修改、引用核查与试片复盘。按当前任务读取；写稿和维护 Skill 不启动生成。本文是模型无关的制作方法，模型专有语法来自当前官方文档和真实适配能力。MiniMax H3 另读 [minimax-h3.md](minimax-h3.md)，实际记录用 [镜头提示词卡](../assets/video-prompt-card.md)。

## 保留三层内容

1. **导演稿**：按用户阅读语言写清观众应该看到什么、发生何种变化、哪些连续性已锁定。来源事实、创作建议和待定项可区分，不让模型格式挤掉叙事。
2. **模型输入稿**：按已核验的模型版本、模式、语言、参考标签和参数编译，保留导演意图；无支持的项目记录为缺口或交给后期，不伪造槽位与控制项。
3. **实际执行记录**：保存宿主最终包装、真实输入及参数、作业和输出对应关系。未提交时写“未执行”；无法取得最终内容时明确证据只到面板保存层。

模型尚未选择时可以完成导演稿与引用准备，模型输入稿保持草案。宿主默认值不是用户选择。已有模型选择和授权继续沿用；真正影响风格、成本或用途的变化才提出决定。

## 先查能力与素材

核对当前提供方、模型与版本、模式、真实参考数量和用途、输入端口／槽位／顺序、接受的语言、是否自动重写或包装、支持的时长／分辨率／比例、声音能力、数量及成本信息。通用节点能接图片或视频，不证明当前模型支持所有输入类型；模型家族的能力也不等于宿主暴露的能力。

需要查当前文档时优先官方；记录链接和核查日期。没有证据的参数写待核验，不从旧价格、模型名称或历史任务推断。若已有工作流显示实际输入，可作为适配证据；不为查能力启动一条收费或生成作业。

打开当前素材检查内容、像素和状态，不能只读清单的 exists。按本轮影响核对真实路径与哈希；源文件未变且已有可靠校验可复用。图片原始像素、宿主缩放、输出分辨率和后期放大分别记录，“2K”“电影级”等提示词不能改变实际输出参数。

## 参考用途与绑定核查

对本镜相关资料建立用途表，不要求把全部项目资料接到生成节点。

| 类别 | 用法与证据 |
|---|---|
| 实际模型输入 | 首／尾／中间帧或身份、运动、声音参考，必须是当前模式支持的用途；记录真实文件、槽位、标签和顺序 |
| 可见校对参考 | 为人和代理比较身份、衣装、道具或空间；可放在主画布便于查看，明确“未输入模型” |
| 跨画布依赖 | 记录真实项目／画布／节点 ID 与用途；无法跨画布连线时保留索引，不假造连线或端口 |
| 候选／历史 | 保留来源和状态，未经采用不进入正式生产引用链 |

画布上的线、管理编号或提示词中的标签都不能单独证明输入已绑定。按工具真实能力检查端口、入边、参考编号、节点输出和最终工作流；只连接本镜实际所需输入，不把整份剧本或全部素材当作参考。选择文本与图片内容冲突时说明冲突；错误已在首帧像素里，优先回 N08 修图或更换已授权素材，不能用长负面词承诺修复。

单首帧只承诺从该画面向前发展，不虚构尾帧。已有中间帧保留原用途，不能因接口只有首尾槽位就擅自改为尾帧；支持不足时保存依赖并说明限制。

## 写一段可拍清楚的变化

先写镜头目的和起终态，再增加实现所需的信息。单镜、多镜与转场由用户任务和叙事决定，不把某次单镜试片的无声、追逐、5秒或镜头数量变成通用规则。

| 层面 | 写到能执行、能检查 | 常见问题 |
|---|---|---|
| 叙事与主体 | 本镜让观众看到的变化；人物身份、数量、衣装及关键物件状态 | 只有情绪标签，或将候选设定写成事实 |
| 首帧与动作 | 已经发生的姿态→接下来的动作→结果；人物自身左右与画面方向分清 | 首帧已在回望，却重新安排另一次回望；动作相互冲突 |
| 空间与连续性 | 站位、路径、遮挡、视线、轴线、道具持有者 | 为露出所有配饰扭转身体；左右镜像或物件换手 |
| 摄影 | 景别和机位；运镜类型、相对方向、有意义的幅度与速度、构图终态 | 把摇镜、横移、变焦和推轨混作同一动作 |
| 光线与外观 | 从真实参考延续光源方向、阴影、色彩及关键材质 | 只堆“电影级、超清”，或每段更换光源 |
| 时间与声音 | 平台生成时长、剪辑用时、动作节奏；对白／声音由谁负责 | 用剪辑时长冒充平台支持参数；跨镜对白重复生成 |
| 排除项 | 本镜具体禁区和已观察到的错误 | 长串与当前画面无关的否定要求 |

动作秒数是导演指导，不等于逐帧控制。需要精确对白或画面时点时保留独立时间索引，以实际成片和剪辑对齐。多镜说明切点、信息变化与声音承接；单镜说明运动连续性。声音独立制作时，保留对白全局索引并明确生成端声音设置，不能只写“无声”就声称输出没有音轨。

## 按需要增强质感

以下是摄影与动画判断，属于可检验的建议，不是特定模型保证或必须全部填写的规则。

- **主体与相机的相对运动**：主体加速时相机是否跟上，景别是否保持，背景视差如何变化；静态机位同样可以表达力量和等待。
- **受力与接触**：脚掌落地、承重和蹬离，手掌与物件贴合，物体受到力后如何移动。选与当前动作有关的接触点即可。
- **惯性与次级运动**：头发、衣角、背包在主体运动后有合理滞后；不要让所有部件等幅同时晃动。
- **遮挡与注意力**：远侧物件自然遮挡，视线先于或跟随动作改变；不为展示设定牺牲空间可信度。
- **光线与材质反应**：明确哪一侧受光、反光何时出现、粗糙布面与旧金属如何区别；保持同一场景条件。
- **表演**：用可见的眼神、呼吸、头部和躯干变化表达动机，避免与剧本情绪相冲突的夸张表演。
- **焦点与剪辑余量**：有叙事用途才移焦、变景别或抖动；末尾按下一镜需要继续运动、落稳或留空，不统一要求定格或继续跑动。

少量相互支持的约束优于互相竞争的要求。先保证首帧、动作和空间可信，再选择摄影与材质细节；精确焦距、快门或物理量只在已验证工具可控时作为参数，否则只能称风格意图。没有生成对照证据，不宣称这些词能保证提升或量化收益。

## 编成模型稿并回读

保留原导演稿与来源，逐项核对编译后是否丢掉身份、物件状态、起终态和声音路线。只将当前模式支持的参考编号写入模型稿；不同模型的特殊标签、参考权重、运镜指令不能直接迁移。

宿主可能添加首帧说明、字段名、声音段落、翻译或负面词。先检查可取得的配置或已有实际工作流：若自动包装，向用户输入栏填写它需要的正文，避免把完整包装再套一层；保存导演稿、输入栏正文和可取得的最终内容对应关系。包装不符合官方推荐时如实记录适配差异，未经授权不修改宿主全局工作流。

保存后回读实际正文、参数、输入和输出，必要时检查界面是否可读、校对图是否可看、状态是否清楚。`current_prompt_version=v2` 与 `output_prompt_version=v1` 可以同时成立；旧输出必须保留旧提示词来源。内容、模型、参考或参数变化均建立新版本，不能把文件保存、作业成功和画面采用混成一个通过状态。

## 采用标准与有限试片

文本交接前检查：来源和已选资产准确、模式和引用可实现、动作与摄影无矛盾、声音及时间可衔接、模型稿可读且无未解析标签。未定项写清影响；只阻塞依赖它的正式提交，其他准备可继续。

实际视频按下列维度记录“可采用／需修／未检查”，用画面时间点和证据解释；不计算看似精确却无校准的综合分数。

| 维度 | 实际观察 |
|---|---|
| 叙事达成 | 关键动作和信息变化是否看得懂 |
| 身份与空间 | 人物、衣装、道具、数量、左右及轴线是否连续 |
| 动作与物理 | 接触、重量、惯性是否可信，有无影响观看的变形闪烁 |
| 摄影与视觉 | 运镜是否有目的且连贯，光线材质与参考是否一致 |
| 时间与声音 | 实际时长、剪辑衔接、声音路线和对白是否正确 |
| 引用与可追溯性 | 输入、提示词、参数、作业和输出能否一一对应 |

用户授权试片或 A/B 时，先定义要验证的一项变化、数量与停止条件；能固定则固定模型、输入、时长、设置和随机种子，同时记录宿主不可控项。按同一标准比较，保留两版及失败；单次样片不证明普遍收益。没有新增生成授权只完成文本审查、保存和回读。效果未改善时回查首帧、动作难度和适配限制，不自动扩批、换模型或收费重试。
