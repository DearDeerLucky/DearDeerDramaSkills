# 剧本讨论记录与图文主理汇报

复制到创作目录后填写。未执行的轮次标“未开始／不适用”，不要为填满模板虚构意见。

## 评审任务

- 作品／稿件版本／原稿路径：
- 本轮编号、覆盖集／场／段落：
- 作者目标、受众、类型与时长：已有信息／待确认。
- 本轮重点、锁定项与禁止改动项：
- 实际方式：独立代理评审／多视角自审（同一代理切换角色）。
- 席位记录：主理人、正方、反方、人物、观众；各席实际执行者及完成状态。
- 允许动作：只审稿／另存候选改稿／复核指定新稿。
- 输入不足与结论适用范围：
- 本轮状态：准备中／审稿中／讨论中／待作者决定／待改稿／待复核／本轮完成。

## 主理汇报（给作者看）

### 这稿目前怎么样

先用一段话给出本轮结论：已经成立的部分、最影响效果的问题和建议下一步。说明范围，避免把单场结论扩大到全剧。

### 值得保留的设计

| 保留项 | 原稿位置与短引文 | 为什么有效 | 改稿时怎样保护 |
|---|---|---|---|

### 关键争议卡（按实际数量复制）

- 争议 ID／标题／影响程度：
- 位置与版本：
- 判断类型：文本事实／分析推断／创作偏好／待验证假设。

先选因果链、人物关系或信息节拍中一种；下图是结构占位，不是剧本事实。填入场号和具体内容，删除无用节点。虚线表示推断或待核验连接，节点文字仍须说明类型。

```mermaid
flowchart LR
  A["原稿事实：场号／段落与事件"] --> B["推断或待核验：承接关系"]
  B -.-> C["原稿事实：场号／段落与结果"]
```

**原文依据**：逐条放短引文和定位；与上图节点对应。

| 视角 | 观点与依据 | 条件／代价／不确定项 |
|---|---|---|
| 正方 | 现稿为何可能成立、值得保留什么 | |
| 反方 | 最强质询及其原文依据 | |
| 人物 | 目标、信息、选择和关系变化 | |
| 观众 | 先看见什么、期待与回报、可能的困惑 | 观众判断注明为假设，除非有实际试读证据 |

**主理裁决**：采纳／部分采纳／不采纳／待验证。写明针对哪项建议、理由、保留异议以及缺失信息。

**修改建议（尚未写入原稿）**：最小改法、替代方案及代价。没有必要改动时写“保留现稿”并说明理由。

```mermaid
flowchart LR
  P["建议：新增或调整的动作／信息"] --> Q["预期效果：需改稿或试读验证"]
```

**怎样验证**：修改后的可观察标准，以及原来有效的部分是否仍成立。

### 改稿任务与需要你决定的事

| 任务 ID／关联争议 | 目标与最小修改 | 影响场次／人物／伏笔 | 必须保留 | 完成标准 | 作者选择／状态 |

## 四席首轮意见（过程记录）

各席先读原稿，不先读其他席结论；同一代理自审记录其局限。按实际意见数量复制：

- 意见 ID／席位／实际执行者：
- 位置（稿件版本、集／场／段落）：
- 原文短引：
- 判断及类型：
- 影响与程度（优点记保留项）：
- 建议、条件与代价：
- 不确定项／把握程度及原因：

## 争议交锋与主理裁决（过程记录）

| 争议 ID／关联意见 | 争议命题 | 正方对最强质询的回应 | 反方对最强辩护的回应 | 人物／观众补充 | 新证据与改变的判断 | 主理裁决及理由 | 保留异议／待验证 |
|---|---|---|---|---|---|---|---|

没有新依据就停止重复交锋。不按票数决定；无重大问题时记录依据，不强造争议。

## 改稿与复核（仅在实际执行后填写）

- 作者采纳的裁决与授权范围：
- 原稿 → 候选新稿的版本／路径：

| 争议／任务 ID | 新稿定位与依据 | 已解决／部分解决／未解决／撤回 | 对原有亮点与后续情节的影响 | 新问题／需返工消费者 |
|---|---|---|---|---|

## 续做与验收

- 原稿、各席意见、主理汇报、交互报告、候选改稿与复核文件路径：按实际存在填写。
- 实际完成层级：能力包检查／演示检查／真实剧本试审／作者验收，逐项记录，互不替代。
- 图文报告检查：引用与版本／图中事实与建议／浏览器交互／窄屏与键盘；未检查项明确保留。
- 下一步：当前可执行动作及唯一必要决定；没有改稿不标记“复核通过”。
