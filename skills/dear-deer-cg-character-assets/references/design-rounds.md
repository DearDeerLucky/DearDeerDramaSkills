# 多轮设计：从选择到完整锁定

每轮记录轮号、输入版本、保留项、可变项、候选、用户原话、采用结果、未决项和下一步。不要只记“选了第二个”，要带方向编号与具体部件。跨会话先恢复记录；可退回任意轮，但只失效其消费者。

## R1 整体方向

展示五方向及其具体差异。用户选一个主方向，或组合明确组件，例如 D02 的脸＋D04 的外套。组合时记录每个组件的来源，重新检查领口与发型、体态与剪裁、道具与收纳是否冲突。主方向维持整体秩序，不把五方向细节全堆在一个人身上。

已有脸或服装被选定时，在其余允许轴上探索。用户要保留旧候选可把它作为一个对照方向，标明它仍是候选；不擅自修改或删除旧图。

## R2 面部与头发

在所选整体方向里给三种可辨认的面部细化方案；三种是建议数量，可按用户要求调整。使用同一年龄区间、物种、取景与材质强度，让眼窝、鼻口、颧颌与发型结构产生差异。一次仅变化本轮讨论的结构。

完整描述：

- 额头高度与太阳穴、眉骨和眉毛形状／密度／断口位置。
- 眼窝深浅、眼距、内外眼角、上／下眼睑、虹膜色；凝视姿态不等于眼部结构。
- 颧骨宽度和前突、面颊软组织、法令及年龄痕迹；不以年龄词自动把角色衰老化。
- 鼻根、鼻梁、鼻尖和鼻翼；嘴宽、唇厚、唇峰、口角和下巴。
- 下颌宽度与角度、脸长宽、耳朵露出、颈部连接。
- 肤色、局部色差、可见纹理、毛发／胡茬；不把真实质感变成脏污或过强噪点。
- 分缝在自身哪侧、额发朝哪侧、耳周与后颈结构，眉断口／痣的位置按自身左右。

用一两个有角色依据的结构识别点，而非“普通帅哥脸＋疤痕”。可推荐方案，但用户选定或明确授权后才记为脸部锁定。用户已明确描述／选定脸时只补漏项，避免为了多轮而强制改脸。

## R3 服装、鞋与配件

沿已选脸和体态，提出三套具有不同剪裁逻辑的服装细化候选。依据世界条件、职业动作、剧情阶段与用户偏好决定材料、层数和装饰，不能默认所有废土角色都穿战术盔甲。

描述从内向外：贴身层 → 外套／披挂 → 腰部收纳 → 裤／裙 → 鞋 → 配件。记录领口和下摆形状、肩与袖结构、闭合部件、缝线／补片、口袋开口与使用方向、材质转换、磨损成因、左右与遮挡关系。

每个配件回答四个问题：为何带、固定在哪、如何取用、行动时如何保持。以人体或主体相对尺度解释大小；精确比例仅在制作确有需要时给出。手部关键交互单独标 PROP 引用和使用状态。不要让束带悬浮、衣服互相穿透、饰物凭空换边。

三级细节层次：远景读轮廓；中景读色块与剪裁；近景读材质、闭合和功能配件。关键细节要可辨、可复现；只在极近距离可见又不影响角色的纹样可降级为可选。

## R4 完整复核与锁定

合并人物事实与全部选项，出完整设计锁定卡和待生成清单。逐项列明脸／发／体态／内外服装／鞋／配件／左右／材质／拓扑／变体，不留“同上”“等等”的关键省略。

若缺口不会影响本次候选图，给明确建议继续试做；若会改变已选身份、拓扑或重要剧情道具，只问一个冲突。用户可用“按这版生成”确认，或明确委托自行补齐；这种授权不必重复索取。

记录**设计锁定**与**图像选定**两类状态。文字已选不代表图像正确；图像修好不自动说明用户审美已接受。正式母版选定后，R1—R3 的弃选方案保留为历史，不继续混入生成提示。

## 迭代、快捷与无提示情形

- “A脸＋B衣服”：保留脸，只调整衣服适配；发现冲突指出具体部位，给可行解法。
- “喜欢鼻子，眼睛太幼”：锁鼻，围绕眼睑、眼窝及眉骨给局部替代；不改年龄、鼻形和衣服。
- “没感觉”：问哪里不合期望（脸／轮廓／服装／材质），再替换相关方案，避免只增加华丽饰品。
- “你来决定”：以已表达目标做推荐并继续，说明未经选择的假设；不把它变成永久个人审美。
- “直接转成CG／修右肘补丁”：走精确转换／修复，保持已选结构，允许跳过探索轮。
- 无提示时先完成最关键期望询问；有回复之后才按其条件筛五方向。长期未回复不能当成选择或批准。

每轮只展示本轮重点和一项选择；完整设计卡始终保存，用户要“全部细节”就展开全卡，不用摘要替代。
